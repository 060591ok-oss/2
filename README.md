# Інтерактивний урок: логічні функції IF, AND, OR, NOT

Навчальна вебсторінка українською мовою для теми «Логічні функції в електронних таблицях».

## Що є на сторінці
- коротка теорія про логічні вирази та функції IF, AND, OR, NOT;
- таблиця істинності;
- інтерактивний тренажер;
- компетентнісне завдання про заявки на шкільну екскурсію;
- тест із 6 запитань, автоматичним підрахунком результату та поясненнями.

## Як переглянути локально
Відкрийте файл `index.html` у будь-якому сучасному браузері. Додаткові програми або бібліотеки не потрібні.

## Як опублікувати через GitHub Pages
1. Увійдіть у GitHub і створіть новий репозиторій, наприклад `logichni-funktsii`.
2. Завантажте в репозиторій файл `index.html` і цей `README.md`.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Оберіть гілку `main` і папку `/(root)`, натисніть **Save**.
6. Після публікації GitHub покаже адресу сторінки в розділі Pages.

> Назва платформи — GitHub (не GitHab). Зміни в `index.html` можна редагувати прямо на GitHub або у текстовому редакторі.
